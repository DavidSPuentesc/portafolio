# Content safety checklist

Before publishing portfolio content:

- Use public or independently owned projects as technical evidence.
- Describe private employment only through role, period, and general capabilities.
- Do not publish client identities, product names, screenshots, source code, architectures, workflows, metrics, datasets, credentials, or internal processes from an employer.
- Do not infer permission from the fact that a project or customer is publicly known.
- Confirm ownership and publication rights before linking a repository, article, image, or document.
- Keep downloadable CVs aligned with the same restrictions as the website.
- Run the confidentiality tests and inspect the production build before every deployment.
- Obtain legal review before publishing any employment-derived case study.
